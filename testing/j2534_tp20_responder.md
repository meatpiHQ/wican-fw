# The speed a TP 2.0 tool gets through the DLL

Command: `python tools/testbench/usb/j2534_tp20_responder.py --blocks 240 --t3-ms 1` (PC, PCAN) in one window, then `C:\Users\Ali\idf_tmp\py32\python.exe -I tools/testbench/usb/j2534_tp20_tester.py --blocks 240 --batch 1` with `WICAN_J2534_HOST=192.168.82.1` (USB-NCM), `WICAN_J2534_COM=auto` (USB CDC serial, env `-u WICAN_J2534_HOST`) or the tunnel's `127.0.0.1:18534` (WiFi), `WICAN_J2534_DLL=<path>` for a built DLL

**The speed a TP 2.0 tool gets through the DLL** (prints `TESTER DONE` + `RESPONDER DONE` with bytes/s, the per-block time, the block-end ACK latency the ECU sees and the projected time of a 2 MB read; `TESTER FAIL` / `RESPONDER FAIL` on a lost frame or a missing ACK; ~16 s for 240 blocks; the second half of the 2026-10-27 report: "usually 20 min to flash, with wican 50"). The responder plays the ECU on PCAN: 255-byte blocks as 37 frames, `0x2N` for ordinary frames, `0x0N` at every 15th (block end: it waits for the tool's ACK `0xBN` before sending more), `0x1N` last; the tester (the DLL, 32-bit) requests blocks, answers every block end, reads one message per `PassThruReadMsgs` (`--batch 16` shows what a tool that asks for 16 pays: the DLL waited for all 16, 19 ms per ACK). Every block end is a round trip bus -> device -> DLL -> tool -> DLL -> device -> bus, and `PassThruWriteMsgs` blocks for the device's ACK (sent after the frame is on the bus): that round trip, not the bus, sets the clock. Measured 2026-10-27 (T3 1 ms, DLL 1.2): block-end ACK latency / per block / 2 MB projection = USB CDC serial 2.8 ms / 70 ms / 9.0 min, USB-NCM 4.7 ms / 76 ms / 9.8 min, WiFi station through the bench AP and the Pi 28.5 ms (p95 49, max 193) / 154 ms / 22.3 min; the real ECU's frame gap adds to all three. DLL 1.4 (`PassThruReadMsgs` on an event instead of a `Sleep(1)` poll, which costs a Windows timer tick: 15.6 ms unless an app raised the resolution, 1.3 to 1.9 ms on this PC) over USB-NCM: 4.4 ms / 56 ms / 7.7 min. 320 clean blocks over CDC after one unexplained `poweron` reboot of the DUT in the first CDC run (PSU steady at 13.5 V / 0.09 A through the reruns)
