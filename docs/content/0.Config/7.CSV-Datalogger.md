# CSV Datalogger

The CSV datalogger writes every decoded AutoPID parameter to a plain CSV file on
the SD card, one file per ignition cycle. It is intended as a lightweight
datalogging fallback (e.g. replacing a Tactrix OpenPort + laptop for road
logging) and works with any tool that reads CSV (MegaLogViewer, Excel, Python).

## Enabling

1. Insert a FAT32-formatted SD card.
2. In the web UI go to **Logger Settings** and set **CSV Datalog (SD)** to
   `Enable`, then reboot.
3. Configure your parameters under **Automate** as usual — every parameter that
   AutoPID decodes (polled PIDs *and* passive CAN filter broadcasts) is logged.

The logger only records while the vehicle ignition is on (detected via battery
voltage, same threshold as Sleep Mode). When the ignition turns off the file is
flushed and closed. A new file is started on the next ignition cycle.

## Output

Files are written to `/sdcard/logs/`:

- `YYYYMMDD_HHMMSS.csv` when the clock is synced (SNTP)
- `unknown_time_<ms-since-boot>.csv` otherwise

Format — one row per sample:

```csv
timestamp_ms,source,name,value,unit
12345,CANFLT,EngineRPM,1546.000,rpm
12350,PID,CoolantTemp,90.000,c
```

- `timestamp_ms`: milliseconds since device boot (monotonic)
- `source`: `CANFLT` (passive broadcast frame), `PID` (custom/vehicle-specific
  poll) or `STD` (standard OBD-II Mode 01 poll)
- `value`: decoded value, as computed by the parameter's expression

Files rotate at 8 MB. Data is flushed to the card at least once per second, so
a power cut loses at most about one second of samples.

## Sampling rate

The logging rate is the AutoPID rate: each parameter's own polling/filter
period under **Automate** controls how often it appears in the log. For fast
logging of a few key channels, give those parameters short periods and disable
parameters you don't need.

## Notes

- This is independent of the SQLite **Logger** (`Logger:` option on the same
  page); both can run at the same time.
- If the SD card is removed or full, the logger stops and retries periodically;
  AutoPID polling is never blocked by SD card writes.
- Retrieve logs via the FTP server or by removing the SD card.
